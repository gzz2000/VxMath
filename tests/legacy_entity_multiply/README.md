# Legacy entity matrix multiplication reference

1,025 affine matrix pairs from experiment E381: one captured game operation
and seeded stress inputs (seed 381), including signed-zero components.
`inputs.bin` contains two row-major 16-component binary32 matrices per case.
`expected.bin` contains the 16 output binary32 components per case. Both files
use little-endian words. Outputs were captured from the original VxMath.dll
nonaliased SSE path (RVA 0x40c0); they are not generated by the implementation
under test. The original DLL SHA-256 is
`bd17dddb747c943e6e090471305aeda7f87cfbca401b3fada36be400285973a2`.
No original executable code is distributed in these fixtures.

The test checks bit-exact output, preservation of both inputs, alias refusal,
and provider removal across repeated enable/disable cycles. A separate native
integration build can define TEST_PHYSICS_MODE_SWITCH and link physics_RT to
exercise its real fast/precise mode API instead of direct registration.
